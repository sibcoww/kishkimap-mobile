# KishkiMap

KishkiMap — учебное кроссплатформенное мобильное приложение для просмотра интересных мест на карте и построения маршрутов между ними.

Приложение разработано на **C# и .NET MAUI**. Оно получает данные из внешнего REST API, показывает точки на карте, позволяет добавлять их в маршрут, менять порядок остановок и рассчитывать путь для пешей прогулки или поездки на автомобиле.

> В исходном коде проект называется `NomadGisMobile`. Репозиторий содержит мобильный клиент; backend работает отдельно.

## Возможности

- регистрация и авторизация пользователя;
- хранение access- и refresh-токенов в `SecureStorage`;
- загрузка точек из REST API;
- отображение точек на карте OpenStreetMap;
- просмотр названия, описания и изображения выбранного места;
- добавление точек в маршрут;
- изменение порядка остановок и удаление отдельных точек;
- построение пешего и автомобильного маршрута;
- отображение расстояния и примерного времени в пути;
- вывод маршрута на мини-карте;
- просмотр общего списка достижений;
- отображение полученных пользователем достижений и награды в XP;
- просмотр профиля, уровня и опыта пользователя;
- гостевой режим для неавторизованных пользователей;
- локальное логирование сетевых ошибок и необработанных исключений.

## Как работает приложение

1. Мобильный клиент обращается к REST API через `ApiClient`.
2. После входа access-токен сохраняется в защищённом хранилище устройства.
3. Точки загружаются из API и отображаются на карте Mapsui поверх OpenStreetMap.
4. Пользователь выбирает места и добавляет их в локальный список маршрута.
5. Для построения маршрута приложение отправляет координаты в публичный сервис OSRM.
6. Полученная геометрия отображается на карте, а пользователь видит расстояние и время в пути.

## API

Мобильный клиент использует внешний backend:

```text
https://nomad-gis-api-7d6a.onrender.com
```

Основные используемые endpoints:

```text
POST /api/v1/auth/register
POST /api/v1/auth/login
GET  /api/v1/points
GET  /api/v1/achievements
GET  /api/v1/profile/my-achievements
GET  /api/v1/profile/me
PUT  /api/v1/profile/me
```

Для работы приложения требуется подключение к интернету. Доступность функций зависит от состояния внешнего API и сервиса маршрутизации OSRM.

## Запуск проекта

### Требования

- Visual Studio 2022 с компонентом **.NET Multi-platform App UI development**;
- .NET 9 SDK;
- Android SDK и эмулятор либо физическое устройство;
- для сборки под iOS и Mac Catalyst требуется macOS и Xcode.

### Через Visual Studio

1. Клонируйте репозиторий:

```bash
git clone https://github.com/sibcoww/kishkimap-mobile.git
```

2. Откройте файл решения:

```text
NomadGisMobile.sln
```

3. Дождитесь восстановления NuGet-пакетов.
4. Выберите целевую платформу и устройство.
5. Запустите проект.

### Через командную строку

Установите MAUI workload:

```bash
dotnet workload install maui
```

Восстановите зависимости:

```bash
dotnet restore NomadGisMobile.sln
```

Пример сборки для Android:

```bash
dotnet build NomadGisMobile/NomadGisMobile.csproj -f net9.0-android
```
